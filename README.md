# שיבוצית

**ניהול תורים לאסיפת הורים** — תוכנה לבתי ספר וישיבות.

בונה את לוח האסיפה אוטומטית: אחים ברצף, הפסקות, אילוצי שעה
להורים, כניסת מפקח וריבוי אנשי צוות. מייצאת לוורד, ל-PDF
ולתמונה. כל הנתונים נשמרים במחשב שלך בלבד.

## הורדה

הגרסה האחרונה — בלשונית [Releases](../../releases/latest).
מורידים את קובץ ההתקנה `shibutzit-<גרסה>-setup.exe` ומריצים.

התוכנה בודקת עדכונים בפתיחה ומציעה להוריד גרסה חדשה כשיש.

## דרישות

- Windows 10 או 11
- רישיון (ניתן לרכישה מהספק). רישיון אחד למוסד, לכמה מחשבים.

## תמיכה

דיווח על תקלה או רעיון — מתוך התוכנה, בכפתור **"דיווח"** או
בתפריט **עזרה**.
